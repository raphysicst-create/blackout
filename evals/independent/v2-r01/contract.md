# BLACKOUT V2 — 게임 구성에 집중하는 5회 루프

사용자 우선순위: 디자인·도시·점등·정전·완료 연출을 유지하고 전기적 제약, 순차적 전략 경험, 의미 있는 수정에 집중한다. [재설계 계획](REVISION-PLAN-2026-09-18.md)의 대규모 HUD/비주얼 재구성은 하지 않는다. 지도는 여백 보정, 선택 추적 등 플레이에 필요한 변경으로 제한한다.

구현자: 현재 작업. 평가자: 기존 별도 작업 `01a0af48-8456-7601-bd66-44dda5017e4d`, `BLACKOUT · 독립 Evals` 섹션. 제품 편집과 채택 판정의 주체를 분리한다. 인간 전략 학습과 재미는 미측정이다.

R1 계약: 기존 도로·도시 SVG, 팔레트, 점등·정전·승리 애니메이션 유지. 기본 모드 보드 framing만 `140 75 1000 510`으로 바꾼다. 시설 중심 선택은 관련 선을 강조하고, 전선 선택은 양 끝 이름을 표시한다. 일반 모드의 재클릭은 삭제가 아니며 명시적 버튼/Delete로 삭제한다. legacy 모드 전기·진행 동작 유지. 화면 끝 시설 접근과 포인터 좌표 변환, 선택 선 삭제의 정확성, 기본 회귀를 독립 검증한다. 물리 터치 및 44px 전 단자 보장은 아직 판정하지 않는다.

다음 회차의 계약은 후보 구현 전 아래에 추가하며, 각 회차의 독립 보고서는 `independent/v2-*`에 보존한다. 실패 재평가는 같은 회차다.
