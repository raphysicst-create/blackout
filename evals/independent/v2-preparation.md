## 공통 검사 설계

- 기본 화면: 1280×720, 1920×1080, 760×550, 600×320, 390×844. 화면 조작성과 전기 결과 불변을 각각 검사한다.
- 입력: 실제 포인터·키보드의 선택/연결/삭제와 테스트 API의 결정적 시나리오를 구분한다. 물리 터치 장치는 수행했을 때만 검증했다고 기록한다.
- 전기 상태: 시설 전압·밝기, 회선 전류·용량, 공급과 귀환, 열·차단 상태를 실제 엔진 값과 대조한다. 밝기 0.8과 전압 80%를 동일시하지 않는다.
- 진행: 안정 확인·예고·일시정지·재시작·초기화, 불가능한 목표와 영구 교착, 중복 이벤트 및 실패 입력의 부작용을 검사한다.
- 시각 상태: 삭제 대상의 양 끝과 실제 삭제 결과, 선택 경로와 관련 시설, 위험 회선의 지속적인 가시성을 확인한다. 예술적 선호나 추적 시간의 인간 성과는 자동 검사로 대체하지 않는다.
- 증거: 고정 후보/해시, 계약, 독립 시나리오, 실제 입력 관찰, 실패 재현, 테스트 범위와 미실행 항목을 분리해 남긴다.

현재 준비 과정에서는 제품 파일을 읽거나 변경하지 않았고, 새 제품 검사도 실행하지 않았다. V2-R1 후보 전달 이후 독립 평가를 시작한다.
