# R3 사전 계약

전략 선택을 만들되 수정 벌점을 부과하지 않는다. R2 독립 판정 후 구현한다.

- 전기 모델은 그대로 유지: 전선 용량 0.75A, 정규화 전원, 전선당 저항. 길이는 게임의 케이블 자원 회계에만 사용한다.
- 자원 사용량 = 현재 전선들의 실제 저장 경로 길이 합. 삭제·단선 시 저장 그래프에서 제거되어 전량 회수된다. 별도 누적 차감/환불 카운터를 두지 않아 중복 환불을 방지한다.
- 단계별 총 보유량 후보: 1,350 / 3,250 / 4,600 / 5,900. 첫 두 시설은 독립 배선이 가능하며 세 번째부터 공유·분산 재설계를 유도한다.
- 도로 기본 경로 계산: 첫 두 독립 2,974, 세 독립 4,926, 네 독립 6,968. 실제 게임의 나란한 선 오프셋 길이는 별도 확인한다.
- 세 시설의 두 갈래 분산 해법: 3,850 / 4,042 / 4,198. 네 시설의 세 분산 해법: 5,036 / 5,364 / 5,416. 엔진에서 세 최종 해법 모두 안정, 최대 전선 전류 약 0.737A로 확인했다.
- 실패한 배선 승인에서는 노드·전선·자원을 변경하지 않는다. 분기는 기존 경로 길이를 보존하고 새 갈래 길이만 추가한다. 확대율과 무관하며 반올림은 표시에서만 한다.
- 드래그 중 필요량을 보여 주고 자원 부족이면 명확히 안내한다. 철거/공유로 회복 가능해야 한다.
- 독립 평가자는 실제 게임 라우팅으로 두 해법 이상을 완성하고 8초 승리 조건을 확인한다. 삭제·분기·실패 드롭·재시작·중복 시도에서 회계 불변식을 검사한다.
- 인간 전략 분포와 재미는 not_run. 독립 에이전트의 결정적 해법은 플레이 가능성 증거다.
