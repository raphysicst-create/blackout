# BLACKOUT — 빛을 잇다

정전된 도시의 배선을 고치는 회로 전략 게임입니다. A·B 두 회선의 전류 여유를 보고 시설을 배분하고, 수요가 바뀌면 기존 연결을 옮겨 도시를 복구합니다.

## 실행

`index.html`을 열거나 `npm start` 후 http://127.0.0.1:4173 에서 플레이합니다. 설치·빌드·외부 서비스가 필요 없습니다.

## 플레이의 순서

1. 배전함 +에서 주택 한쪽으로, 주택 반대쪽에서 같은 배전함 −로 연결합니다.
2. 다음 구역에는 어두운 시설 두 개와 낡은 연결이 있습니다. 기존 선을 선택해 끊고 새 공급·귀환을 만들어 밝기를 회복합니다.
3. 펌프를 연결할 회선을 고릅니다. 같은 회선에 많은 시설을 모으면 전류가 몰립니다.
4. 추가 수요가 예고됩니다. 회선 여유를 보고 미리 옮기거나, 과열 원인을 찾아 부하를 재배치합니다.
5. 최종 수요까지 안정되면 도시 복구 연출과 결과가 이어집니다. 다음 구역은 수요가 늘어나는 시설이 달라집니다.

케이블 길이·철거 비용은 없습니다. A/B 회선은 각각 0.75 A까지 공급합니다. 전구 기본 수요는 0.30 A, 펌프는 0.45 A입니다. 과전류가 6초 지속되면 해당 회선이 차단됩니다. 다른 회선으로 시설을 옮기고 최대 3초 냉각 후 꺼진 배전함을 눌러 복구합니다. 원인을 해결하지 않은 재투입은 거절됩니다.

시설이 어두운 것과 회선이 뜨거운 것은 다릅니다. 시설의 전압이 낮으면 밝기가 부족하고, 회선의 전류가 용량을 넘으면 과열됩니다. 두 시설을 한 경로에 차례로 넣으면 전압이 나뉩니다. 시설 상태와 A/B 전류 표시를 함께 살펴보세요.

## 조작

- 연결: 단자에서 다른 단자로 드래그. 키보드는 Tab으로 단자를 선택하고 Enter로 시작·완료합니다.
- 분기: A/B 배전함 단자에서만 시작합니다. 시설 단자에는 외부 전선 하나씩만 연결할 수 있습니다.
- 삭제: 전선을 선택하고 **연결 끊기** 또는 Delete. 방금 삭제한 선은 **삭제 취소**로 되돌릴 수 있습니다. 다른 연결을 편집하면 이전 취소는 끝납니다.
- 관찰: 시설 본체를 누르면 관련 배선을 강조합니다. A 도구로 전류를 살펴볼 수 있습니다.
- 회선 복구: 차단된 배전함 본체 → **회선 복구**. 키보드는 고정 회선 선택 → 복구 버튼을 사용합니다.
- 일시정지: Space 또는 일시정지 버튼. 도움말과 탭 이탈 중에도 게임 시간·열은 멈춥니다.

새 수요는 현재 문제가 해결되고 안정된 뒤 예고됩니다. 예방에 성공하면 정전 없이 완료할 수 있습니다. 반드시 실패하거나 특정 횟수만큼 삭제해야 하는 조건은 없습니다.

## 개발과 평가

`npm test`, `npm run check`로 자체 회귀를 실행합니다. 기본 모드의 구현자 브라우저 회귀는 `evals/v2-self.html`, 별도 평가자의 후보별 판정은 `evals/v2-loop.md`를 확인하세요. 이전 케이블·자유 분기 방식의 테스트는 새 규칙에 그대로 적용하지 않습니다. `tests/browser.html`은 명시적 legacy 모드의 기존 회귀입니다.

`?test=1`은 자동 시간을 끄고 `BlackoutTesting.advance(seconds)`로 진행합니다. `reset({seed:101})`, `snapshot()`, `circuits()`, `connect`, `remove`, `undo`, `resetFeeder`를 사용할 수 있습니다. 일반 플레이 시드는 101/202/303입니다.

`BlackoutSession.export()`와 `history()`로 로컬 메모리 기록을 가져올 수 있습니다. 서버로 전송하지 않습니다. 가속 테스트의 완료 시간은 사람의 플레이 시간이나 재미 측정이 아닙니다.

전압은 정규화한 1 V 모델입니다. 밝기 0.8은 공급 전압 약 89.4%에 해당하며 80% 전압과 다릅니다. 전선 길이와 화면 확대는 전기 계산에 영향을 주지 않습니다. 공급·귀환과 배전함 내부의 양극은 실제로 분리되어 있고 자동 귀환선은 없습니다.
