구현자: 현재 작업. 평가자: 기존 별도 작업 `01a0af48-8456-7601-bd66-44dda5017e4d`, `BLACKOUT · 독립 Evals` 섹션. 제품 편집과 채택 판정의 주체를 분리한다. 인간 전략 학습과 재미는 미측정이다.

## R2 계약 — 두 회선과 전기적 한계

R4 증거: [최종 독립 판정](independent/v2-r04-revision1-review.md). 전기·진행 7/7, Node 52/52. 예고와 차단 상태의 안내가 작은 화면에서 시설 이름·수치와 겹치는 문제를 수정했고 최종 8개 상태가 통과했다. 실제 포인터로 일시정지·도움말·위험 재투입 거절·안전 재배치 후 복구를 확인했다. 자동 검증이며 인간 참여자는 0명이다.

기본 모드에서 케이블 예산을 제거한다. 기존 전압 1 V 정규화, 정격 부하, 6초 발열과 3초 냉각을 유지한다. 전원은 고정 공급·귀환으로 A/B 배전함에 연결되며 각 회선의 용량은 .75 A다. 일반 전선 중간 분기를 막고 배전함에서만 가지를 만든다. 시설 단자마다 외부 전선은 하나, 직렬 연결은 허용, 시설 연결 경로가 A/B를 동시에 묶으면 거절한다. 전원 직결·고정선 삭제로 용량 우회 불가. 고정선은 과열 시 차단되고, 충분히 냉각되고 재투입 계산이 안전할 때만 복구된다. 일반 전선은 기존 단선 모델을 유지한다. 보호 상태는 재연결로 초기화하지 않는다.

필수 평가: 두 배분 완주, 실제 전압·전류 보존, 같은 회선 부하 증가로 고정 간선 과열, 차단 이후 다른 회선 유지, 재투입 거절/허용, 전원 직결·배전함 직결·혼합 귀환·시설 단자 다중 연결 거절, 길이 무제한, 자유분기·고정선 삭제 불가. 배전함은 기존 형태·색·빛을 재사용하며 새로운 디자인 체계나 점수 UI를 추가하지 않는다. 단계별 수리 상황과 수요 변화는 R3/R4 범위다.

## R3 계약 — 연결을 늘리는 것에서 기존 배선 수정으로

첫 주택 점등 후, 새로 열린 구역의 두 시설이 낡은 직렬 배선으로 연결된 상태를 보여 준다. 기존 플레이어 회로를 강제로 변형하지 않는다. 낮은 시설 전압을 표시하고, 문제가 있는 중간 전선을 선택해 삭제할 수 있다는 첫 안내를 제공한다. 이미 쓰는 시설 단자에 새 전선을 추가하는 것은 불가하므로 구조를 바꾸려면 삭제가 필요하다. 공급과 귀환은 수동으로 연결하며 자동 정답 완성은 없다. 유효한 대체 해법도 다음 단계로 진행한다. 한 번 삭제 취소를 지원하되 열은 삭제 전 값과 이후 경과 냉각 규칙을 일관되게 처리하고 재삽입 시 새 전선으로 초기화하지 않는다. 새 토폴로지 편집 후에는 과거 취소를 무효화해 잘못된 회로를 합성하지 않는다.

필수 평가: 첫 회로 보존, 새 직렬 회로 실제 전압 부족, 기존 선 삭제 및 병렬 복구, 역순 연결, 실수 삭제 취소, 열/보호 상태 유지, 도움 중 시간 정지, 수리 미완료 중 수요 억제, 삭제 횟수를 승리 조건으로 사용하지 않음.

## R4 계약 — 안정된 배선도 다음 수요를 보고 판단한다

기존 네 시설 안정 후 즉시 승리하지 않고, 특정 시설의 전력 수요 증가를 3초 예고한다. 시설 저항/정격 수요를 바꿔 실제 전류 계산에 반영한다. 첫 구역 초안은 전구 3개와 펌프에서 전구 한 시설이 .30→.45 A 수요로 증가하는 상황이다. 두 회선의 총량은 여전히 충분하고, 각각 .30+.45로 나누는 두 해법이 존재해야 한다. 예고 중에도 수정할 수 있고 예방에 성공하면 정전 없이 진행한다. 예고 직전 문제가 발생하면 예고가 보류되고, 복구 후 다시 시작해 위기 중 사건을 쌓지 않는다.

차단은 해당 회선과 시설의 결과로 표현하고 기존 BLACKOUT·점등 연출은 유지한다. 차단 직전 전류·용량·연결 시설을 기록하여 0 A인 사후 상태만 보고 원인을 놓치지 않게 한다. 안전한 다른 회선은 계속 켜져야 한다. 차단기 복구 후 최종 안정 8초와 도시 감상 7초는 유지한다.

필수 평가: 예고 단 한 번 적용, 단순 통과로 최종 수요 건너뛰기 불가, 안정 중 예방·과열 후 수정·차단 후 복구 세 경로, 같은 부하의 같은 배선 재생은 같은 전류와 차단 결과, 일시정지·재시작 중 예고와 열 일관.

## R5 계약 — 세 구역과 최종 전략 전이

세 구역은 같은 규칙과 수치를 사용하되 수요가 증가하는 시설을 바꾼다. 첫 구역은 기존 배선 수리 안내를 제공하고 후속 구역은 이미 익힌 설명을 축소한다. 모든 구역에서 새로 연결하거나 기존 배선을 옮기는 두 가지 이상 최종 배분을 실제 엔진으로 검증한다. 이전 배분이 그대로 안전한 경우는 유지할 수 있고, 특정 구역에서 위험한 복사 배분은 실제 회선 전류에 의해 차단되어야 한다. 결과는 사용 케이블·조작량 점수 대신 최종 회선 부하와 실제 수요 변경·복구 결과를 보여 준다. 3구역 순환, 같은 구역 재시작, 기록 초기화, 회로도, 키보드·포인터 전체 흐름을 확인한다. 인간의 전략 전이는 관측하지 않았다면 not_run을 유지한다.

구체 설정: 101은 주택, 202는 골목, 303은 공원의 수요가 .30→.45 A로 증가한다. A/B 이름만 바꾼 같은 해법을 두 전략으로 세지 않고, 펌프에 함께 배정한 시설이 다른 두 해법을 확인한다. 회로도는 배전함을 전구 기호로 표시하지 않고 공급·귀환이 분리된 접속점으로 표시한다. 새 배전함에 도시 점등용 빛 웅덩이를 추가하지 않아 기존 시설 점등에 따른 도시 공개 연출을 보존한다. README와 최종 회귀를 새 규칙에 맞춰 갱신하고, 원본 도시/도로·애니메이션 정의의 보존을 확인한다.
