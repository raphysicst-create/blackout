# BLACKOUT — 빛을 잇다

정전된 도시에 전선을 연결해 빛을 돌려주는 회로 전략 게임입니다. 한정된 케이블로 길을 공유하고, 전류가 몰리면 배선을 나눠 복구합니다. 전구의 밝기, 움직이는 전류, 전선의 열이 연결 상태를 알려 줍니다.

## 실행

**`index.html`을 더블클릭하면 바로 실행됩니다.** 인터넷, 패키지 설치, 빌드가 필요 없습니다. 마우스와 터치를 지원합니다.

Node.js가 있다면 프로젝트 폴더에서 다음 명령으로 로컬 서버를 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 여세요. 서버 종료는 터미널에서 `Ctrl+C`입니다.

## 플레이

| 하고 싶은 일 | 조작 |
| --- | --- |
| 연결하기 | 건전지·시설 양옆의 작은 단자에서 다른 단자까지 끌어 놓기 |
| 갈래 만들기 | 두 번째 시설이 등장하면, 기존 전선 중간에서 새 시설의 단자로 끌어 놓기 |
| 전선 끊기 | 전선을 선택하고 **연결 끊기** 누르기. 길게 누른 뒤 바깥으로 끌어도 됩니다. |
| 전류 살펴보기 | 두 번째 시설이 등장하면 **A** 도구를 선택하고 전선 누르기 |
| 케이블 관리 | 드래그 중 필요량 확인. 전선을 끊으면 사용한 케이블을 전량 회수 |
| 다시 연결하기 | 연결 도구 선택 또는 `C` |
| 잠시 멈추기 | 일시 정지 버튼 또는 `Space`. 다른 탭으로 이동해도 일시 정지됩니다. |
| 도움말·소리 | 화면 아래 도움말과 소리 버튼. 소리는 처음에 꺼져 있습니다. |

키보드로도 `Tab`으로 단자를 선택하고 `Enter`로 연결을 시작·완료할 수 있습니다. 선택한 전선은 `Delete`로 끊고, `Esc`로 선택이나 진행 중인 연결을 취소합니다.

전선은 도시의 도로와 시설 진입로를 따라 직각으로 꺾여 연결됩니다. 같은 도로의 독립 전선은 나란히 표시되며, 서로 지나쳐도 자동으로 연결되지 않습니다. 전선 중간에서 분기할 때는 기존 경로가 유지됩니다.

**첫 연결:** 건전지 오른쪽 +단자에서 전구 왼쪽 단자로 연결한 뒤, 전구 오른쪽 단자에서 건전지 왼쪽 −단자로 돌아오는 전선을 그리세요. 두 전선이 모두 이어지면 전구가 켜집니다.

현재 시설들이 안정되면 다음 수요를 예고합니다. 안정 유지 4초와 예고 3초가 필요하고 시설 등장 사이에는 최소 12초 간격을 둡니다. 미해결·과열·냉각 중에는 다음 수요를 쌓지 않습니다. 네 시설을 모두 안정적으로 밝힌 채 **8초**를 유지하면 복구가 완료됩니다. 도시를 7초간 감상한 뒤 결과 카드와 **회로도 보기**가 열립니다. 5분이 지나도 계속 복구할 수 있습니다.

시설 수에 따라 케이블 총량은 **1,350 → 3,250 → 4,600 → 5,900**으로 늘어납니다. 기존 단자나 전선에서 길을 함께 쓰면 케이블을 절약할 수 있지만, 한 전선에 너무 많은 전류를 모으면 과부하가 납니다. 철거와 단선 모두 케이블을 전량 돌려주며 수정 벌점은 없습니다.

과열 중에는 전류·용량·단선까지 남은 시간이, 안전해진 뒤에는 냉각 시간이 표시됩니다. 끊어진 길을 복구하면 현재 시설들이 다시 안정됐다는 피드백을 받습니다.

완료 후 **다음 구역 복구하기**로 세 구역을 순환합니다. 첫 구역은 전구 세 개와 펌프 하나이며, 다음 구역들은 서로 다른 위치에 펌프 두 개가 등장합니다. 두 펌프를 한 간선에 모으면 과부하가 날 수 있으므로 배분을 다시 생각해야 합니다. 일시정지 화면의 **처음부터 다시**는 같은 구역을 재시도합니다.

## 개발·검증

```sh
npm test
npm run check
```

`npm test`는 회로 계산과 과부하·냉각 등을 검증하고, `npm run check`는 모든 제품 JavaScript 문법을 확인합니다. [tests/browser.html](http://127.0.0.1:4173/tests/browser.html)은 기존 시간표를 명시적으로 유지하는 `legacy` 회귀 18개입니다. **이 검사만으로 새 기본 게임을 검증하지 않습니다.** 기본 진행·자원·위기·재도전의 별도 평가와 파일 해시는 [독립 평가 실행 기록](evals/LOOP.md)에 있습니다.

개발용 `index.html?test=1`은 시간을 자동 진행하지 않고 `BlackoutTesting.advance(seconds)`로만 진행합니다. `reset({seed:202})`로 시나리오를 재현할 수 있습니다. 일반 플레이는 `?seed=101`, `202`, `303`으로 구역을 지정할 수 있습니다. 다른 시드는 101로 돌아갑니다.

행동 기록은 브라우저 메모리에만 남습니다. `BlackoutSession.export()`로 현재 런, `BlackoutSession.history()`로 재도전 전 최대 다섯 런을 가져올 수 있습니다. 서버로 전송하지 않으며 페이지를 닫으면 사라집니다. 실제 사람 플레이 결과와 테스트 API로 가속한 기록을 섞지 마세요.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css` | 게임 화면과 반응형 스타일 |
| `game.js` | 입력, 단계 진행, 빛·전류 표현, 소리 |
| `engine.js` | DOM과 분리된 회로·발열 계산 |
| `director.js` | 안정 상태에 반응하는 수요·예고·도움 진행 |
| `cable.js` | 실제 경로 길이에 따른 자원 회계 |
| `runs.js` | 재현 가능한 세 구역의 수요 구성 |
| `telemetry.js` | 로컬 행동 기록과 내보내기 |
| `city.js` | SVG 도시 지도 |
| `router.js` | 도로를 따르는 직선 경로와 전류 이동 좌표 |
| `schematic.js` | 플레이 결과의 회로도 |
| `server.cjs` | 의존성 없는 로컬 정적 서버 |

### 회로 모델

건전지는 **왼쪽 −극 / 오른쪽 +극**, 전구와 펌프는 **서로 분리된 두 단자**를 갖습니다. 반드시 `건전지 + → 시설 한쪽 단자 → 시설 내부 → 반대쪽 단자 → 건전지 −`의 닫힌 회로를 만들어야 전류가 흐릅니다. 한쪽만 연결하면 0 A이며, 공급선이나 귀환선 중 하나를 끊어도 해당 회로는 꺼집니다. 결과 회로도에도 직접 연결한 전선만 표시하며, 자동 귀환선은 없습니다.

전선과 기기를 저항으로 다루는 절점 전압 해석으로 직렬·병렬·혼합 회로의 전류를 계산합니다. 기기 양쪽을 같은 극에 연결하거나 전선으로 우회하면 기기에 전압 차가 생기지 않아 켜지지 않습니다. 전선이 교차해도 자동으로 연결되지 않으며, +극과 −극을 기기 없이 잇는 합선은 큰 전류로 전선을 과열시킵니다. 합선 상태에서는 시설 복구가 인정되지 않습니다.

전압은 1로 정규화하며 전구의 정격 전류는 **0.30 A**, 모터는 **0.45 A**입니다. 작은 전선 저항과 건전지 내부 저항 때문에 실제 전류와 밝기는 약간 낮아집니다. 공급선과 귀환선 모두 용량 **0.75 A**를 적용합니다. 이를 초과하면 **6초**에 걸쳐 과열되어 끊어지고, 안전한 상태에서는 최대 **3초**에 걸쳐 식습니다. 길이는 케이블 자원에만 반영하며, 전기 모델의 전선 저항은 길이에 따라 바뀌지 않습니다. 전기적으로 안전한 회로라도 게임의 케이블 총량 안에서 설계해야 합니다.
