# R2 사전 계약

R1 판정 전의 설계 준비이며 제품 코드는 바꾸지 않는다.

- 수요 등장에 필요한 조건: 현재 등장 시설 전체 정상, 열이 남지 않음, 최소 4초 안정.
- 이후 3초 예고. 직전 수요 등장부터 최소 12초 간격을 유지한다.
- 즉시 해결한 정책의 다음 사건까지 강제 대기 상한은 12초. 마지막 8초 승리 안정화는 별도다.
- 예고 중 불안정해지면 예고 취소 후 안정 시간을 처음부터 센다. 일시정지·도움말에서는 시간이 진행하지 않는다.
- 진행이 안 되는 동안 새 시설을 쌓지 않으며 25초 후 해당 단계에서 한 번만 도움을 준다.
- 전류계/분기는 두 번째 수요 등장과 함께 연다. ‘원인을 살필 필요가 생겼을 때 도구가 잠김’을 방지한다.
- 원본 18개 브라우저 회귀의 시간 시나리오는 명시적 legacy 모드로 보존한다. 기본 플레이의 새 진행을 별도 독립 통합 검사로 평가하며 legacy 통과만으로 R2를 인정하지 않는다.
- 기존 회로 엔진과 마지막 8초 안정 조건, 종료 후 감상은 유지한다.
- 독립 검증: 빠른 해결, 45초 지연, 잘못 연결, 복구 중 예고 취소, 중복 등장 금지, 중단/재개, 실제 기본 모드 브라우저 진행.
- 사람의 완료 시간·체감 공백은 not_run이며 자동 정책의 시간과 구분한다.
