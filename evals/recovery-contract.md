# R4 사전 계약

- 과부하를 더 자주 강제하지 않는다. 안전한 설계에는 기존처럼 위기가 없다.
- 기존 6초 가열·3초 냉각·0.75A 규칙은 변경하지 않는다.
- 가장 위험한 전선의 실제 전류, 열 비율, 현재 열 기준 예상 단선 잔여 초를 표시한다.
- 과부하가 해소된 뒤 다시 발생하면 새 episode로 기록하고 안내를 다시 제공한다. 기존 런당 한 번 안내를 대체한다.
- 단선 후에는 ‘복구 중’ 상태와 정상 시설 수를 보여 준다. 당시 수요가 전체 안정되어야 복구 완료를 한 번 기록한다.
- 새 수요는 R2 규칙에 따라 복구 중 들어오지 않는다. 복구에 벌점이나 새 자원 비용을 추가하지 않는다.
- 측정 이벤트, 과부하 시작/종료/단선/복구와 시설 상태 전이를 로컬 기록으로 남긴다. 시간은 active 초이며 도움말/정지에서 누적하지 않는다.
- 독립 검증: 2회 별도 과부하와 재안내, 열과 카운트다운 일치, 정지/재개, 과열 직전 해소, 단선 후 성공, 안전 회로의 무경고, 재시작 초기화.
- 사람의 원인 이해/45초 복구 성공률은 not_run. 자동 시나리오와 실제 에이전트 입력을 분리 보고한다.
