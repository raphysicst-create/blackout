# 게임성 개선 전으로 롤백

사용자 요청: “게임성 개선 전으로 롤백해”.

기준은 최초 개선 루프 전에 저장한 `evals/checkpoints/r00`이며 Git `624f50f` 제품과 일치한다. 원본 제품 파일 8개와 README·브라우저 회귀 페이지를 복구하고, 개선 도입 모듈 5개와 전용 Node 테스트 2개를 활성 경로에서 제거했다. 정적 배포 산출물 `dist/`도 같은 원본 제품으로 맞췄다.

기존 디자인·연출과 원래 0/30/90/225초 시설 등장 규칙, 65초 전류계·90초 분기 해금으로 돌아갔다. 이후 두 차례 게임성 개선의 진행·케이블·배전함·수요 변화·구역 순환은 현재 게임에서 실행되지 않는다.

복원 전 루트·테스트·dist 파일과 호스팅 설정의 백업은 `backups/before-gameplay-rollback-20260918-191215/`에 있다. 평가 기록, 원본 기획·디자인 자료, 호스팅 프로젝트와 dist 설정은 보존했다. Git 이력을 다시 쓰거나 공개 배포를 실행하지 않았다.

원본 game.js SHA-256: `9d984527926075b89510c66cb6675ebf675261e4d47060c3b07c446c08a87c65`.

검증: 원래 Node 테스트 45/45, 문법 검사, 실제 브라우저 통합 회귀 18/18 통과. 별도 에이전트의 읽기 전용 감사에서 복원 파일 10개가 624f50f와 일치하고 제품 8개가 독립 baseline 해시와 일치함을 확인했다. dist 8개는 루트와 바이트 동일하며 호스팅 설정은 복원 전 백업과 동일하다.
