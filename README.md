# BLACKOUT — 빛을 잇다

정전된 도시에 전선을 연결해 빛을 돌려주는 약 4~5분의 게임입니다. 전구의 밝기, 움직이는 전류, 과부하로 흔들리는 전선이 연결 상태를 알려 줍니다.

## 실행

**`index.html`을 더블클릭하면 바로 실행됩니다.** 인터넷, 패키지 설치, 빌드가 필요 없습니다. 마우스와 터치를 지원합니다.

Node.js가 있다면 프로젝트 폴더에서 다음 명령으로 로컬 서버를 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 여세요. 서버 종료는 터미널에서 `Ctrl+C`입니다.

## 플레이

| 하고 싶은 일 | 조작 |
| --- | --- |
| 연결하기 | 건전지·시설 양옆의 작은 단자에서 다른 단자까지 끌어 놓기 |
| 갈래 만들기 | 90초 이후, 기존 전선 중간에서 새 시설의 단자로 끌어 놓기 |
| 전선 끊기 | 전선을 선택하고 **연결 끊기** 누르기. 길게 누른 뒤 바깥으로 끌어도 됩니다. |
| 전류 살펴보기 | 65초 이후 **A** 도구를 선택하고 전선 누르기 |
| 다시 연결하기 | 연결 도구 선택 또는 `C` |
| 잠시 멈추기 | 일시 정지 버튼 또는 `Space`. 다른 탭으로 이동해도 일시 정지됩니다. |
| 도움말·소리 | 화면 아래 도움말과 소리 버튼. 소리는 처음에 꺼져 있습니다. |

키보드로도 `Tab`으로 단자를 선택하고 `Enter`로 연결을 시작·완료할 수 있습니다. 선택한 전선은 `Delete`로 끊고, `Esc`로 선택이나 진행 중인 연결을 취소합니다.

전선은 도시의 도로와 시설 진입로를 따라 직각으로 꺾여 연결됩니다. 같은 도로의 독립 전선은 나란히 표시되며, 서로 지나쳐도 자동으로 연결되지 않습니다. 전선 중간에서 분기할 때는 기존 경로가 유지됩니다.

**첫 연결:** 건전지 오른쪽 +단자에서 전구 왼쪽 단자로 연결한 뒤, 전구 오른쪽 단자에서 건전지 왼쪽 −단자로 돌아오는 전선을 그리세요. 두 전선이 모두 이어지면 전구가 켜집니다.

시설은 플레이 시간 **0초·30초·90초·225초**에 차례로 등장합니다. 네 시설을 모두 안정적으로 밝힌 채 **8초**를 유지하면 복구가 완료됩니다. 복구된 도시를 잠시 감상한 뒤 결과 카드와 **회로도 보기**가 열립니다. 전선이 끊어져도 다시 연결할 수 있으며, 5분이 지나도 계속 복구할 수 있습니다.

## 개발·검증

```sh
npm test
npm run check
```

`npm test`는 회로 계산과 과부하·냉각 등을 검증하고, `npm run check`는 JavaScript 문법을 확인합니다. 브라우저 통합 검증은 서버 실행 후 [tests/browser.html](http://127.0.0.1:4173/tests/browser.html)을 열어 실행합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css` | 게임 화면과 반응형 스타일 |
| `game.js` | 입력, 단계 진행, 빛·전류 표현, 소리 |
| `engine.js` | DOM과 분리된 회로·발열 계산 |
| `city.js` | SVG 도시 지도 |
| `router.js` | 도로를 따르는 직선 경로와 전류 이동 좌표 |
| `schematic.js` | 플레이 결과의 회로도 |
| `server.cjs` | 의존성 없는 로컬 정적 서버 |

### 회로 모델

건전지는 **왼쪽 −극 / 오른쪽 +극**, 전구와 펌프는 **서로 분리된 두 단자**를 갖습니다. 반드시 `건전지 + → 시설 한쪽 단자 → 시설 내부 → 반대쪽 단자 → 건전지 −`의 닫힌 회로를 만들어야 전류가 흐릅니다. 한쪽만 연결하면 0 A이며, 공급선이나 귀환선 중 하나를 끊어도 해당 회로는 꺼집니다. 결과 회로도에도 직접 연결한 전선만 표시하며, 자동 귀환선은 없습니다.

전선과 기기를 저항으로 다루는 절점 전압 해석으로 직렬·병렬·혼합 회로의 전류를 계산합니다. 기기 양쪽을 같은 극에 연결하거나 전선으로 우회하면 기기에 전압 차가 생기지 않아 켜지지 않습니다. 전선이 교차해도 자동으로 연결되지 않으며, +극과 −극을 기기 없이 잇는 합선은 큰 전류로 전선을 과열시킵니다. 합선 상태에서는 시설 복구가 인정되지 않습니다.

전압은 1로 정규화하며 전구의 정격 전류는 **0.30 A**, 모터는 **0.45 A**입니다. 작은 전선 저항과 건전지 내부 저항 때문에 실제 전류와 밝기는 약간 낮아집니다. 공급선과 귀환선 모두 용량 **0.75 A**를 적용합니다. 이를 초과하면 **6초**에 걸쳐 과열되어 끊어지고, 안전한 상태에서는 최대 **3초**에 걸쳐 식습니다. 각 시설에 독립된 공급선과 귀환선을 만들면 네 시설을 모두 안정적으로 켤 수 있습니다.
